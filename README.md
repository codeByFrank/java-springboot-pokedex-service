# Pokédex Service — Java & Spring Boot

Ein Lernprojekt aus dem Java-Bootcamp bei neue fische.

Die Anwendung soll Pokémon-Daten aus der PokéAPI abrufen
und eine persönliche Favoriten-Sammlung in MongoDB verwalten.

## Technologien

- Java
- Spring Boot
- Spring Web und RestClient
- Spring Data MongoDB
- Spring Validation
- Lombok
- Maven

## Projektstatus

Das Projekt-Setup ist angelegt. Die Funktionen werden
schrittweise implementiert und getestet.
